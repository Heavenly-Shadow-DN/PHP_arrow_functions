# Контрольные вопросы — Практическая работа «PHP: стрелочные функции (fn)»

## 1. Чем стрелочная функция fn отличается от классической анонимной функции function?

Главные отличия:

- Тело fn — всегда ровно одно выражение, которое сразу вычисляется и возвращается. У классической анонимной функции тело может содержать любое число инструкций.
- В fn не нужно писать return — значение выражения возвращается само.
- Внешние переменные fn захватывает автоматически, по значению, в момент создания. Классической анонимной функции их нужно явно перечислять в конструкции use.
- Классическая анонимная функция может захватывать переменные по ссылке (use (&$x)) и изменять их; fn так не умеет — она работает только с копиями значений.

## 2. Как fn захватывает переменные из внешней области видимости? Почему изменение переменной после создания функции не влияет на неё?

fn захватывает внешние переменные автоматически (без use), по значению и в момент создания функции. Внутрь функции попадает копия значения, сделанная при её объявлении. Поэтому, если позже изменить внешнюю переменную, внутри fn останется старое значение — функция хранит свою копию, а не ссылку на внешнюю переменную. Пример из задачи 2: после создания $applyDiscount я поменял $discount с 0.9 на 0.5, но функция продолжила считать со скидкой 0.9.

## 3. Можно ли записать в теле fn несколько инструкций? Как обойти это ограничение, если логика сложная?

Нельзя — тело fn всегда одно выражение. Если логика сложная, есть два способа:

- использовать классическую анонимную функцию function (...) { ... } с return — она поддерживает любое число инструкций;
- упаковать несколько действий в одно выражение: например, через тернарный оператор, match или присвоить значение внутри выражения. Но если код перестаёт быть читаемым, правильнее просто взять обычную анонимную функцию.

## 4. Что возвращают array_map, array_filter и array_reduce? Чем отличаются их callback-функции?

- array_map(fn, $array) возвращает новый массив, где каждый элемент пропущен через функцию. Callback принимает один элемент и возвращает его новый (преобразованный) вариант.
- array_filter($array, fn) возвращает массив из тех же элементов, но только тех, для которых callback вернул true (т.е. это фильтрация, а не преобразование). Callback принимает элемент и должен вернуть логическое значение.
- array_reduce($array, fn, $initial) сворачивает массив в одно значение (число, строку). Callback принимает два аргумента: накопитель (результат предыдущего шага или начальное значение) и текущий элемент, и возвращает новое значение накопителя.

Отличие: у map callback «элемент → новый элемент», у filter «элемент → true/false», у reduce «накопитель + элемент → новое значение накопителя».

## 5. Как работает оператор <=> и почему он удобен в usort()?

Оператор <=> (spaceship, «космический корабль») сравнивает два значения и возвращает: -1, если левое меньше правого; 0, если они равны; 1, если левое больше правого. usort() принимает функцию сравнения двух элементов, которая должна возвращать именно отрицательное число, 0 или положительное — то есть <=> даёт ровно то, что ожидает usort. Поэтому запись usort($users, fn($a, $b) => $a['age'] <=> $b['age']) заменяет несколько строк с if/else. Чтобы отсортировать по убыванию, достаточно поменять операнды местами: $b <=> $a.

## 6. Что выведет код `$f = fn($x) => fn($y) => $x * $y; echo $f(2)(5);`? Объясните.

Выведет 10.

$f — вложенная стрелочная функция: fn($x) => fn($y) => $x * $y. Внешняя fn($x) возвращает другую функцию fn($y) => $x * $y, в которую автоматически захвачено значение $x. Вызов $f(2) возвращает эту внутреннюю функцию с $x = 2, а сразу следующий вызов (5) подставляет $y = 5 и вычисляет 2 * 5 = 10. Такой приём называется каррингом (currying): функция от двух аргументов представлена как функция от одного аргумента, возвращающая функцию от второго.
